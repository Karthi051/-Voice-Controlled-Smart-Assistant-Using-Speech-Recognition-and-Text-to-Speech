Task_Manager

A smart task scheduling application with voice input, camera integration, obstacle detection, 2-minute alarms, calendar view, and modern UI. Built with Flutter, Riverpod, and SQLite.

✨ Features

🎯 Core Functionality

  • ✅ Smart Scheduling - Create tasks with start and optional end times
  • ✅ Recurring Tasks - Daily, weekly, monthly, or custom day patterns
  • ✅ Sleep Mode Protection - Prevents scheduling during configured sleep hours (default: 10 PM - 6 AM)
  • ✅ Overlap Detection - Intelligent conflict checking prevents double-booking
  • ✅ Dual View Modes - Toggle between List and Timeline views
  • ✅ Rich Notifications - 10-minute reminders + exact-time alarms
  • ✅ Category System - Education, Work, Health, Home, Shopping with color coding

🎨 Modern UI Design

  • 🎨 Gradient Task Cards - Category-based color gradients with shadows
  • 📊 Timeline View - Chronological daily schedule with visual indicators
  • 📱 Responsive Design - Optimized for all screen sizes
  • ✍️ No Text Overflow - All text properly truncated with ellipsis
  • 📅 Enhanced Calendar - TableCalendar with task markers
  • 🌈 Material 3 Theming - Beautiful color schemes and typography

⚙️ Smart Validations

  • 🛌 Sleep time blocking with customizable hours
  • ⏰ Time conflict detection (checks all recurring occurrences)
  • ⌛ End time must be after start time
  • 📝 Title required validation
  • 💬 User-friendly error dialogs with actionable messages

🏗️ Architecture

State Management (Riverpod)

Providers:
├── tasksProvider          // All tasks (StateNotifierProvider)
├── dateProvider          // Selected date (StateProvider<DateTime>)
├── timeProvider          // Selected time (StateProvider<TimeOfDay>)
├── categoryProvider      // Selected category (StateProvider)
└── viewModeProvider      // List/Timeline toggle (StateProvider<bool>)

Data Layer

Task Model:
├── id: int?                    // Database ID
├── title: String               // Task name
├── note: String                // Description
├── category: TaskCategory      // Category enum
├── time: String                // Start time (formatted)
├── endTime: String?            // End time (optional)
├── date: String                // Task date
├── recurrenceType: enum        // Recurrence pattern
└── customDays: List<int>?      // Custom day numbers (1-31)

RecurrenceType enum:
├── none      // One-time task
├── daily     // Every day
├── weekly    // Same day each week
├── monthly   // Same date each month
└── custom    // Selected days (1-31)

Database Schema (SQLite v3)

CREATE TABLE tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  note TEXT,
  date TEXT NOT NULL,
  time TEXT NOT NULL,
  endTime TEXT,              -- v3: Optional end time
  category TEXT NOT NULL,
  recurrenceType TEXT,       -- v2: Recurrence pattern
  customDays TEXT            -- v2: Comma-separated days
);

Migration History:

  • v1: Initial schema (id, title, note, date, time, category)
  • v2: Added recurrenceType and customDays for recurring tasks
  • v3: Added endTime for time range support

🛌 SleepModeService

Protects sleep schedule from late-night task creation.

Key Methods:

- setSleepTimes(start, end)       // Configure sleep hours
- setSleepEnabled(bool)           // Toggle feature
- getSleepStartTime()             // Retrieve configured start
- getSleepEndTime()               // Retrieve configured end
- isInSleepTime(TimeOfDay)       // Check if time is blocked

Implementation:

// Handles midnight crossing (e.g., 22:00 → 06:00)
Future<bool> isInSleepTime(TimeOfDay time) async {
  final enabled = await isSleepEnabled();
  if (!enabled) return false;

  final start = await getSleepStartTime();
  final end = await getSleepEndTime();

  final timeInMinutes = time.hour * 60 + time.minute;
  final startInMinutes = start.hour * 60 + start.minute;
  final endInMinutes = end.hour * 60 + end.minute;

  if (startInMinutes > endInMinutes) {
    // Crosses midnight (e.g., 22:00 to 06:00)
    return timeInMinutes >= startInMinutes || timeInMinutes < endInMinutes;
  } else {
    // Normal range (e.g., 01:00 to 05:00)
    return timeInMinutes >= startInMinutes && timeInMinutes < endInMinutes;
  }
}

⚠️ TaskValidationService

Prevents scheduling conflicts and validates task data.

Key Methods:

Overlap Detection Logic:

static bool hasTimeOverlap(Task newTask, List<Task> existing, {int? excludeTaskId}) {
  final newStart = Helpers.stringToTimeOfDay(newTask.time);
  final newEnd = newTask.endTime != null
      ? Helpers.stringToTimeOfDay(newTask.endTime!)
      : TimeOfDay(hour: (newStart.hour + 1) % 24, minute: newStart.minute);

  final newStartMinutes = newStart.hour * 60 + newStart.minute;
  final newEndMinutes = newEnd.hour * 60 + newEnd.minute;

  for (final task in existing) {
    if (excludeTaskId != null && task.id == excludeTaskId) continue;
    if (task.date != newTask.date) continue;

    final existingStart = Helpers.stringToTimeOfDay(task.time);
    final existingEnd = task.endTime != null
        ? Helpers.stringToTimeOfDay(task.endTime!)
        : TimeOfDay(hour: (existingStart.hour + 1) % 24, minute: existingStart.minute);

    final existingStartMinutes = existingStart.hour * 60 + existingStart.minute;
    final existingEndMinutes = existingEnd.hour * 60 + existingEnd.minute;

    // Overlap if: new starts before existing ends AND new ends after existing starts
    if (newStartMinutes < existingEndMinutes && newEndMinutes > existingStartMinutes) {
      return true;  // Conflict detected!
    }
  }
  return false;
}

🛌 Sleep Mode Guide

Purpose

Protect your sleep schedule by preventing task creation during configured sleep hours.

Configuration

Access Settings:

  1. Tap Settings icon (⚙️) in home screen app bar
  2. Sleep Mode section appears at top

Configure Hours:

  1. Toggle Sleep Mode - ON/OFF switch
  2. Sleep Start Time - Tap to set (e.g., 10:00 PM)
    • Time picker opens
    • Select hour and minute
    • Tap OK
  3. Wake Up Time - Tap to set (e.g., 6:00 AM)
    • Time picker opens
    • Select hour and minute
    • Tap OK
  4. View Active Range - Info card shows: "Active: 10:00 PM - 6:00 AM"

Default Settings:

  • Enabled: true
  • Sleep Start: 22:00 (10:00 PM)
  • Sleep End: 06:00 (6:00 AM)

Behavior

When Enabled:

  • Creating/editing task during sleep hours → ❌ Dialog appears
    • Icon: 🛌 Bedtime
    • Title: "Sleep Mode Active"
    • Message: "This time is reserved for sleep (10:00 PM - 6:00 AM). Please choose a different time or adjust your sleep settings."
    • Actions:
      • Change Time - Dismiss and select different time
      • Go to Settings - Navigate to settings to adjust hours

When Disabled:

  • No sleep time restrictions
  • Tasks can be created at any time

Midnight Crossing: Sleep mode correctly handles ranges that cross midnight:

  • 22:00 → 06:00 blocks: 10 PM-11:59 PM and 12:00 AM-5:59 AM
  • 01:00 → 05:00 blocks: 1:00 AM-4:59 AM (normal range)

⚠️ Conflict Resolution

Overlap Detection

How It Works:

  1. User creates/edits task with time range
  2. System checks all existing tasks on same date
  3. For each existing task:
    • If no end time → assumes 1-hour duration
    • Calculates start/end in minutes
    • Checks if ranges overlap: 
      Overlap = (newStart < existingEnd) AND (newEnd > existingStart)
  4. If overlap found → Show conflict dialog

Conflict Dialog:

  • Icon: ⚠️ Warning
  • Title: "Time Slot Conflict"
  • Content:
    • "This time slot is already occupied by:"
    • Task Card with:
      • Conflicting task title
      • Time range (e.g., "3:00 PM - 4:30 PM")
      • Category color border
    • "Please choose a different time slot."
  • Action: OK button (dismiss)

Resolution Strategies

Option 1: Change Start Time

  • Move task earlier or later
  • Ensure no overlap with existing tasks

Option 2: Adjust End Time

  • Shorten duration
  • Reduce overlap period

Option 3: Change Date

  • Schedule on different day
  • Same time slot may be available

Option 4: Edit Conflicting Task

  • Go to home screen
  • Edit the conflicting task
  • Move it to different time
  • Return and try again

Example Scenario:

Existing: "Study Math" → 3:00 PM - 4:30 PM
New:      "Team Meeting" → 4:00 PM - 5:00 PM
Overlap:  4:00 PM - 4:30 PM (30 minutes)
Result:   ❌ Conflict detected

Solutions:
✅ Move meeting to 4:30 PM - 5:30 PM
✅ Move meeting to 2:00 PM - 3:00 PM
✅ Shorten study to 3:00 PM - 4:00 PM

🛠️ Troubleshooting

Notifications Not Appearing

Symptoms:

  • ✅ Task created successfully
  • ❌ No notification at scheduled time
  • ❌ No reminder 10 minutes before

Solutions:

  1. Check Notification Permissions

    Settings → Apps → Task Scheduler → Permissions → Notifications
✅ Ensure "Allowed" is selected

  2. Verify Exact Alarm Permission (Android 12+)

    Settings → Apps → Task Scheduler → Alarms & reminders
✅ Enable "Allow setting alarms and reminders"

  3. Disable Battery Optimization

    Settings → Battery → Battery optimization
→ Find "Task Scheduler"
→ Select "Don't optimize"

  4. Check Do Not Disturb Mode

    Settings → Sound & vibration → Do Not Disturb
→ Ensure app is in "Priority" or "All" modes

  5. Test Notification System

    • App shows test notification on launch
    • Look for: "✅ Notifications Working!"
    • If not appearing → Permission issue

  6. Review Logs

    flutter run
# Look for:
# ✅ Notification permission: PermissionStatus.granted
# ✅ Scheduling 10-min reminder (ID: X)

  7. Reinstall App

    • Uninstall completely
    • Reinstall from build
    • Grant all permissions
    • Test with new task

Sleep Mode Not Blocking

Symptoms:

  • Sleep mode enabled in Settings
  • Creating task at 11 PM allowed
  • No sleep mode dialog

Solutions:

  1. Verify Settings

    Settings screen → Sleep Mode
✅ Toggle is ON (blue)
✅ Sleep Start: 22:00 (10:00 PM)
✅ Sleep End: 06:00 (6:00 AM)

  2. Check Time Picker Format

    • Ensure AM/PM selected correctly
    • 10:00 PM = 22:00 in 24-hour format
    • 6:00 AM = 06:00 in 24-hour format

  3. Restart App

    • Settings saved to SharedPreferences
    • Restart app to reload settings
    • Try creating task again

  4. Verify isInSleepTime Logic

    • If still not working, check implementation
    • Midnight crossing handled correctly
    • Minutes calculation accurate

Overlaps Not Detected

Symptoms:

  • Creating overlapping tasks allowed
  • No conflict dialog appears
  • Multiple tasks at same time

Solutions:

  1. Verify Same Date

    • Overlap detection only checks same date
    • Tasks on different dates won't conflict
    • Check selected date matches existing task

  2. Check Time Ranges

    • Ensure times actually overlap
    • Example overlap: 
      Task A: 3:00 PM - 4:00 PM
Task B: 3:30 PM - 5:00 PM
Overlap: 3:30 PM - 4:00 PM ✅
    • Example no overlap: 
      Task A: 3:00 PM - 4:00 PM
Task B: 4:00 PM - 5:00 PM
No overlap ❌ (end = next start)

  3. Database Migration

    • Ensure database migrated to v3
    • Check endTime column exists
    • Old tasks may need end time added

  4. Edit vs Create

    • When editing, current task excluded from check
    • Prevents false positive for same task
    • Normal behavior

  5. Check Validation Code

    • TaskValidationService.hasTimeOverlap() called
    • allTasks includes all tasks for date
    • excludeTaskId set correctly when editing

App Crashes

Common Causes & Fixes:

  1. Database Migration Failed

    # Clear app data
flutter clean
flutter pub get
# Uninstall app from device
flutter run

  2. Null Safety Errors

    • Ensure all providers initialized
    • Check task model parsing
    • Verify database schema matches code

  3. Build Errors

    # Clean build
flutter clean
rm -rf build/
flutter pub get
flutter build apk

  4. Gradle Issues

    • Check android/build.gradle versions
    • Gradle: 8.7
    • AGP: 8.6.0
    • Kotlin: 2.1.0

Text Overflow

If text still overflows:

  1. Check Widget Implementation

    Text(
  task.title,
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
  softWrap: true,
)

  2. Verify Container Constraints

    • Use Expanded or Flexible in Rows
    • Set maxWidth if necessary
    • Avoid hardcoded widths

  3. Font Size

    • Larger fonts need more space
    • Reduce maxLines if needed
    • Adjust padding/margins
