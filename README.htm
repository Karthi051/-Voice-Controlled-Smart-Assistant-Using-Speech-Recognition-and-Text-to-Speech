scheduleTaskNotifications(Task) // Schedule 10-min reminder + exact alarm - cancelTaskNotifications(int) // Remove notifications on delete/edit - showTestNotification() // Debug: Test notification system - printPendingNotifications() // Debug: List scheduled notifications ``` **Features:** - Android 13+ permission handling - Exact alarm scheduling with `exactAllowWhileIdle` - Timezone-aware scheduling - LED lights, vibration, and sound - Notification channels with importance ### 🛌 SleepModeService Protects sleep schedule from late-night task creation. **Key Methods:** ```dart - setSleepTimes(start, end) // Configure sleep hours - setSleepEnabled(bool) // Toggle feature - getSleepStartTime() // Retrieve configured start - getSleepEndTime() // Retrieve configured end - isInSleepTime(TimeOfDay) // Check if time is blocked ``` **Implementation:** ```dart // Handles midnight crossing (e.g., 22:00 → 06:00) Future isInSleepTime(TimeOfDay time) async { final enabled = await isSleepEnabled(); if (!enabled) return false; final start = await getSleepStartTime(); final end = await getSleepEndTime(); final timeInMinutes = time.hour * 60 + time.minute; final startInMinutes = start.hour * 60 + start.minute; final endInMinutes = end.hour * 60 + end.minute; if (startInMinutes > endInMinutes) { // Crosses midnight (e.g., 22:00 to 06:00) return timeInMinutes >= startInMinutes || timeInMinutes < endInMinutes; } else { // Normal range (e.g., 01:00 to 05:00) return timeInMinutes >= startInMinutes && timeInMinutes < endInMinutes; } } ``` ### ⚠️ TaskValidationService Prevents scheduling conflicts and validates task data. **Key Methods:** ```dart - hasTimeOverlap(Task, List, excludeTaskId?) // Check conflicts - getConflictingTask(Task, List) // Find overlapping task - formatTimeRange(start, end) // Display helper - getTaskDurationMinutes(Task) // Calculate duration ``` **Overlap Detection Logic:** ```dart static bool hasTimeOverlap(Task newTask, List existing, {int? excludeTaskId}) { final newStart = Helpers.stringToTimeOfDay(newTask.time); final newEnd = newTask.endTime != null ? Helpers.stringToTimeOfDay(newTask.endTime!) : TimeOfDay(hour: (newStart.hour + 1) % 24, minute: newStart.minute); final newStartMinutes = newStart.hour * 60 + newStart.minute; final newEndMinutes = newEnd.hour * 60 + newEnd.minute; for (final task in existing) { if (excludeTaskId != null && task.id == excludeTaskId) continue; if (task.date != newTask.date) continue; final existingStart = Helpers.stringToTimeOfDay(task.time); final existingEnd = task.endTime != null ? Helpers.stringToTimeOfDay(task.endTime!) : TimeOfDay(hour: (existingStart.hour + 1) % 24, minute: existingStart.minute); final existingStartMinutes = existingStart.hour * 60 + existingStart.minute; final existingEndMinutes = existingEnd.hour * 60 + existingEnd.minute; // Overlap if: new starts before existing ends AND new ends after existing starts if (newStartMinutes < existingEndMinutes && newEndMinutes > existingStartMinutes) { return true; // Conflict detected! } } return false; } ``` --- ## 🎨 UI Components ### Modern Task Tile **Design Features:** - User creates/edits task with time range 2. System checks all existing tasks on **same date** 3. For each existing task: - If no end time → assumes 1-hour duration - Calculates start/end in minutes - Checks if ranges overlap: ``` Overlap = (newStart < existingEnd) AND (newEnd > existingStart) ``` 4. If overlap found → Show conflict dialog **Conflict Dialog:** - Icon: ⚠️ Warning - Title: "Time Slot Conflict" - Content: - "This time slot is already occupied by:" - **Task Card** with: - Conflicting task title - Time range (e.g., "3:00 PM - 4:30 PM") - Category color border - "Please choose a different time slot." - Action: **OK** button (dismiss) ### Resolution Strategies **Option 1: Change Start Time** - Move task earlier or later - Ensure no overlap with existing tasks **Option 2: Adjust End Time** - Shorten duration - Reduce overlap period **Option 3: Change Date** - Schedule on different day - Same time slot may be available **Option 4: Edit Conflicting Task** - Go to home screen - Edit the conflicting task - Move it to different time - Return and try again **Example Scenario:** ``` Existing: "Study Math" → 3:00 PM - 4:30 PM New: "Team Meeting" → 4:00 PM - 5:00 PM Overlap: 4:00 PM - 4:30 PM (30 minutes) Result: ❌ Conflict detected Solutions: ✅ Move meeting to 4:30 PM - 5:30 PM ✅ Move meeting to 2:00 PM - 3:00 PM ✅ Shorten study to 3:00 PM - 4:00 PM ``` --- ## 🎯 Usage Examples ### Example 1: Daily Study Routine ```yaml Task: title: "Study Mathematics" category: Education (🎓 Green) date: Dec 6, 2025 time: "3:00 PM" endTime: "4:30 PM" recurrence: Daily notes: "Complete homework chapter 5" Result: - App shows test notification on launch - Look for: "✅ Notifications Working!" - If not appearing → Permission issue 6. **Review Logs** ```bash flutter run # Look for: # ✅ Notification permission: PermissionStatus.granted # ✅ Scheduling 10-min reminder (ID: X) ``` 7. **Reinstall App** - Uninstall completely - Reinstall from build - Grant all permissions - Test with new task ### Sleep Mode Not Blocking **Symptoms:** - Sleep mode enabled in Settings - Creating task at 11 PM allowed - No sleep mode dialog **Solutions:** 1. **Verify Settings** ``` Settings screen → Sleep Mode ✅ Toggle is ON (blue) ✅ Sleep Start: 22:00 (10:00 PM) ✅ Sleep End: 06:00 (6:00 AM) ``` 2. **Check Time Picker Format** - Ensure AM/PM selected correctly - 10:00 PM = 22:00 in 24-hour format - 6:00 AM = 06:00 in 24-hour format 3. **Restart App** - Settings saved to SharedPreferences - Restart app to reload settings - Try creating task again 4. **Verify isInSleepTime Logic** - If still not working, check implementation - Midnight crossing handled correctly - Minutes calculation accurate ### Overlaps Not Detected **Symptoms:** - Creating overlapping tasks allowed - No conflict dialog appears - Multiple tasks at same time **Solutions:** 1. **Verify Same Date** - Overlap detection only checks same date - Tasks on different dates won't conflict - Check selected date matches existing task 2. **Check Time Ranges** - Ensure times actually overlap - Example overlap: ``` Task A: 3:00 PM - 4:00 PM Task B: 3:30 PM - 5:00 PM Overlap: 3:30 PM - 4:00 PM ✅ ``` - Example no overlap: ``` Task A: 3:00 PM - 4:00 PM Task B: 4:00 PM - 5:00 PM No overlap ❌ (end = next start) ``` 3. **Database Migration** - Ensure database migrated to v3 - Check `endTime` column exists - Old tasks may need end time added 4. **Edit vs Create** - When editing, current task excluded from check - Prevents false positive for same task - Normal behavior 5. **Check Validation Code** - `TaskValidationService.hasTimeOverlap()` called - `allTasks` includes all tasks for date - `excludeTaskId` set correctly when editing ### App Crashes **Common Causes & Fixes:** 1. **Database Migration Failed** ```bash # Clear app data flutter clean flutter pub get # Uninstall app from device flutter run ``` 2. **Null Safety Errors** - Ensure all providers initialized - Check task model parsing - Verify database schema matches code 3. **Build Errors** ```bash # Clean build flutter clean rm -rf build/ flutter pub get flutter build apk ``` 4. **Gradle Issues** - Check `android/build.gradle` versions - Gradle: 8.7 - AGP: 8.6.0 - Kotlin: 2.1.0 ### Text Overflow **If text still overflows:** 1. **Check Widget Implementation** ```dart Text( task.title, maxLines: 2, overflow: TextOverflow.ellipsis, softWrap: true, ) ``` 2. **Verify Container Constraints** - Use `Expanded` or `Flexible` in Rows - Set `maxWidth` if necessary - Avoid hardcoded widths 3. **Font Size** - Larger fonts need more space - Reduce `maxLines` if needed - Adjust padding/margins --- ## 🤝 Contributing Contributions are welcome!
